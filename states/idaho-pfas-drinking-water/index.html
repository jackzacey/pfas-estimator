How the count works

What is included

Each active community water system with complete monitoring is counted once, even if it is linked with several ZIP codes. Private wells are excluded, and UCMR 5 did not comprehensively monitor every small system. This page does not apply Idaho's state-specific standards or determine compliance. Use the official state or territory drinking-water program for current regulatory information.
