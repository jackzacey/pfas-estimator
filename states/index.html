Interpretation guardrails

Read state summaries in context

Observed monitoring

Results are observed UCMR 5 public-water records linked to ZIP codes, not modeled contamination or household measurements.

Partial coverage

ZIPs without a retained detection are absent, and private wells or many small systems may not be represented.

Shared systems

One public water system can serve multiple ZIP codes, so neighboring state-page records are not always independent.

Coverage note

Only 1 ZIP code (96543, Andersen Air Force Base) is represented in the analytic dataset for Guam — not enough coverage to summarize meaningfully as a state-level page. The ZIP_TO_STATE crosswalk has been fixed so this ZIP is no longer silently dropped from the live map, but no static page is generated for it.
